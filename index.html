The fang sword 1st
  1. execute as @a[hasitem=[{item=netherite_sword,location=slot.weapon.mainhand},{item=netherite_sword,location=slot.weapon.mainhand,data=0,quantity=0}]] at @s run tag @e[r=4,c=3,type=!player,type=!xp_orb,type=!item] add fanged
  2. execute as @e[tag=fanged] at @s run playsound mob.evocation_illager.prepare_summon @a
  3. execute as @e[tag=fanged] at @s run playsound mob.evocation_illager.cast_spell @a
  4. execute as @e[tag=fanged] at @s run summon evocation_fang ~ ~ ~
  5. execute as @e[tag=fanged] run effect @s slowness 3 2 true
  6. replaceitem entity @a[hasitem=[{item=netherite_sword,location=slot.weapon.mainhand},{item=netherite_sword,location=slot.weapon.mainhand,data=0,quantity=0}]] slot.weapon.mainhand 0 netherite_sword
  7. tag @e[tag=fanged] remove fanged
